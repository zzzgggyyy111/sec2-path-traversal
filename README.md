文件下载接口只过滤了两个点，攻击者换成编码写法和绝对路径，把服务器上的配置文件读走了：下载服务收到的用户路径没有经过完整解码与规范化，绝对路径、符号链接、空字节、保留设备名和分隔符变体都能绕过根目录限制。契约是路径必须先解码再规范化，规范化后必须仍在根目录之内，绝对路径与盘符一律拒绝，符号链接必须解析后判定，空字节与保留名必须拒绝，分隔符变体必须统一处理，批量校验各路径独立。不变量是任何解析后的真实路径都落在根目录内，同一路径两次校验结果相同。

在仓库根目录运行 python -m pytest tests -q 查看公开测试结果。
